# SIMENU – Smart Intelligent Menu & Grocery Planner

Proof of Concept (PoC) untuk proposal rancangan agen cerdas SIMENU.
Mata kuliah Kecerdasan Buatan, Program Studi Informatika, Universitas Bhayangkara Jakarta Raya (UTS/ETS Ganjil 2026/2027).

## Isi
- `UTS-KB_F5B1_PoC_SIMENU.ipynb` : notebook lengkap (retrieval TF-IDF, pemetaan bahan, solver ILP, verifier, evaluasi 30 profil)
- `poc_simenu.py` : versi ringkas solver ILP + verifier (skenario A, B, C)
- `requirements.txt` : pustaka yang dibutuhkan

## Cara menjalankan
```bash
pip install -r requirements.txt
python poc_simenu.py
```
Atau buka notebook di Jupyter/Colab lalu pilih *Run All*.

## Catatan data
Harga, waktu masak, dan nilai gizi adalah **data sampel ilustrasi**, bukan data pasar atau TKPI.
